# БАБАХ! Лови и взрывай!

Весёлая браузерная игра для детей от 3 лет: лопаем летающие шарики с яркими эффектами и звуками.

## Как запустить

1. Откройте файл `index.html` в любом современном браузере (Chrome, Firefox, Edge, Safari).
2. Нажмите **ИГРАТЬ** или **УМНЫЙ БАБАХ**.
3. Нажимайте на шарики пальцем или мышкой!

Сервер и установка не нужны — достаточно открыть файл локально.

## Режимы

| Режим | Описание |
|--------|----------|
| **ИГРАТЬ** (Свободный БАБАХ!) | Лопай любые шарики. Нет таймера и проигрыша. |
| **УМНЫЙ БАБАХ** | Внизу показан цвет — лопаем шарики этого цвета. Неправильный цвет не наказывается, только слегка «пружинит». |

## Виды шариков

- **Красный** — громкий «БАБАХ!»
- **Жёлтый** — делится на маленькие шарики
- **Синий** — превращается в желейную лужицу
- **Зелёный** — первый тап = отскок, второй = лопается
- **Радужный** — салют из конфетти
- **Огромный** — лопается после трёх нажатий и смешно деформируется

## Сюрпризы

Каждые 6–10 попаданий случается что-то весёлое:

- гигантский шарик
- дождь из шариков
- все шарики с смешными рожицами
- радужный шарик с салютом

## Управление

- **Мышь / тачскрин** — нажать на шарик
- **⏸** — пауза
- **🏠** — в меню
- **🔊** — вкл/выкл звук
- **Esc** или **Пробел** — пауза / продолжить

## Файлы

```
index.html  — страница игры
style.css   — оформление интерфейса
game.js     — логика, анимация, звук
README.md   — эта инструкция
```

Технологии: HTML5 Canvas, CSS3, JavaScript (без внешних библиотек). Звук — Web Audio API. Картинки рисуются программно.

## Для родителей

- Нет рекламы и внешних ссылок
- Нет ограничения по времени и наказаний за ошибки
- Звук умеренный, без резких вспышек
- Звук включается только после первого нажатия
- Подходит для компьютера, планшета и телефона
